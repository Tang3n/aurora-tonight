# Tech stack

What runs today and what is planned. Each item links to the ADR that argues for it ([index](adr/README.md)).
Status as of 2026-11-19. There is no backend and no database by design ([ADR 14](adr/0014-no-accounts-no-backend.md)).

## Application

| Layer | Today | Planned | ADR |
|---|---|---|---|
| Language | TypeScript (strict): 5.9 in packages and web, 6.0 in the Expo app | same | 13 |
| UI | web: React 19; app: React Native 0.88 + Expo Router (Expo SDK 58) | web: React Router prerender for shareable pages | 13 |
| Shared logic | `packages/core`: hooks, TanStack Query, view model, i18n, spot ranking, alert decision | + camera scorecard | 13 |
| Data fetching / cache | fetchers in `packages/data`; caching and refresh by TanStack Query | same | 13 |
| Build | web: Vite 8; app: Expo prebuild + Gradle (local), Hermes bytecode | EAS Build for store releases | 13 |
| Tests | Vitest: model 49, core 14, data 4; model-vs-Node checks on Hermes (debug screen) | automated device test (Maestro or Detox) | 4 |
| Repo layout | npm workspaces: `packages/model`, `packages/data`, `packages/core`, `apps/web`, `apps/mobile` | same | 13 |
| Graphics | web: WebGL "living sky" shader, d3-geo oval map; app: static SVG sky (react-native-svg) | app: animated sky with React Native Skia | 13 |
| Maps | MapLibre GL JS 6 (web, lazy-loaded) and MapLibre Native 11 (app), OpenFreeMap "dark" tiles | same | 6, 13 |
| Fonts | Space Grotesk + Inter (Google Fonts on the web, `@expo-google-fonts` in the app) | same | — |
| Astronomy | suncalc; AACGM-v2 grid generated by `tools/gen_aacgm_grid.py` (aacgmv2) | same | 4 |
| i18n | `packages/core/src/i18n.ts` (EN / CS / NO) | same | — |

## Data sources

| Source | Used for | Licence / terms |
|---|---|---|
| NOAA SWPC (OVATION, Kp forecast, real-time solar wind) | aurora activity | US public domain |
| MET Norway Locationforecast | clouds at the home point | CC BY 4.0; clients must identify themselves (the app sends its own User-Agent) |
| Open-Meteo forecast (multi-location) | clouds for spots ("where to go") | CC BY 4.0, free for non-commercial use |
| Open-Meteo geocoding | place search | CC BY 4.0 |
| OpenStreetMap via Overpass (build time) | seeded spots | ODbL, attribution required |
| OpenFreeMap / OpenMapTiles | map tiles | free, attribution required |
| GFZ Kp archive, ERA5 via Open-Meteo, FMI keograms | validation; later the camera scorecard | research use, see `validation/README.md` |
| Light pollution layer | spot darkness (Bortle) | open question: licence unclear |

## Tooling

GitHub Actions (typecheck, test, build, deploy), Python in `tools/` and `validation/` for the AACGM grid, spots and
validation, Android SDK + JDK 21 for local app builds (see `apps/mobile/README.md`).
