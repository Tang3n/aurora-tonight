# Tech stack

What runs today, what is on a branch, and what is planned. Each planned item links to the ADR that argues for it
([index](adr/README.md)). Status as of 2026-11-19.

## Backend (phase 2, none today)

| Need | Choice | ADR |
|---|---|---|
| Auth | Supabase Auth: email magic link, Google | 8 |
| Database | Postgres + PostGIS, Row Level Security, SQL migrations in `supabase/migrations/` | 8, 9 |
| Files | Supabase Storage: WebP ~2048 px + ~400 px thumbnails, EXIF removed on device | 10 |
| Jobs | Supabase Edge Functions (Deno) triggered by `pg_cron` every 10 min | 11 |
| Push | Web Push (VAPID) for browsers, Expo push / FCM / APNs for the apps | 11, 13 |
| Backups | weekly `pg_dump` from GitHub Actions (free plan has no backups) | 8 |

Free-plan limits checked 2026-11-19: 500 MB database, 1 GB storage, 5 GB egress, 50k MAU, pause after 7 idle days.

## Data sources

| Source | Used for | Licence / terms |
|---|---|---|
| NOAA SWPC (OVATION, Kp forecast, real-time solar wind) | aurora activity | US public domain |
| MET Norway Locationforecast | clouds at the home point | CC BY 4.0, identify the client, cache |
| Open-Meteo forecast (multi-location) | clouds for spots ("where to go") | CC BY 4.0, free for non-commercial use |
| Open-Meteo geocoding | place search | CC BY 4.0 |
| OpenStreetMap via Overpass (build time) | seeded spots | ODbL, attribution required |

| Light pollution layer | spot darkness (Bortle) | open question: licence unclear |
